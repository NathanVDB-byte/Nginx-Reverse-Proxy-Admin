# Nginx-Reverse-Proxy-Admin
Un panneau d’administration web simple et sécurisé pour gérer les vhosts Nginx sur Debian 12, sans éditer manuellement les fichiers de configuration. L’application permet de créer, activer, désactiver et supprimer des vhosts HTTP, puis d’activer automatiquement HTTPS via Let’s Encrypt (Certbot --nginx) pour chaque domaine.
